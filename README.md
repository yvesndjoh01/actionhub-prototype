# KOICA ActionHub — Unofficial Participant Prototype

A lightweight MVP showing how participants could turn Action Plans into measurable 90-day implementation journeys.

## Features
- Action Plan builder
- 90-Day challenge
- KPI-oriented tracking
- Progress/evidence updates
- Cohort impact dashboard with illustrative demo data
- Local "AI Action Plan Coach" prototype
- SmartDry Cameroon example preloaded
- Browser localStorage persistence
- Browser print / PDF export

## Run
Open `index.html` directly in a browser.

## Deploy
Upload these files to GitHub, then deploy the repository to Vercel or Netlify.

## Important
This is an unofficial participant prototype. Do not use KOICA logos or imply official endorsement without permission.
